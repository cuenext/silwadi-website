# Silwadi Multi-Page Hospital Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the crowded single-page Silwadi Dental Center site with a calm, professional multi-page healthcare website while preserving the working local-preview workflow and existing real doctor assets.

**Architecture:** Keep the project dependency-free: static HTML pages, one shared `styles.css`, and one small shared `app.js` for navigation, reveal behavior, accordions, and doctor-directory filtering. Essential doctor/treatment content moves into crawlable HTML instead of being generated by JavaScript. Consultation CTAs route to `contact.html#consultation`; Phase 1 does not introduce a backend form.

**Tech Stack:** HTML5, CSS3, vanilla JavaScript, existing Windows PowerShell local server, Python standard-library smoke tests for development verification only.

**Spec:** `docs/superpowers/specs/2026-08-22-silwadi-multipage-hospital-redesign-design.md`

## Global Constraints

- Visual direction: hospital-level structure and authority with premium private-clinic polish.
- Primary CTA wording: **Book a Consultation**.
- Doctor-specific CTA wording: **Book a consultation with Dr. [Name]**.
- Palette remains navy/teal/white with restrained accents; avoid excessive gradients and glassmorphism.
- Use real supplied clinic portraits; no specialty badges over faces or bodies.
- Important doctor/treatment content must be present in HTML where practical.
- Phase 1 pages: Home, Doctors, Dr. Munir profile, Treatments, Dental Implants, About, Digital Dentistry, Locations, Contact.
- No invented medical claims, awards, accreditations, affiliations, patient outcomes, or guarantees.
- Preserve `START-SILWADI.bat`, phone-preview access, auto-pull behavior, and the existing `assets/` directory.
- Local preview must continue to require no Python or Node.js; Python is only a developer-side verification tool.

```js
const header = document.querySelector('[data-header]');
const menuButton = document.querySelector('[data-menu-button]');
const mobileNav = document.querySelector('[data-mobile-nav]');

if (header) {
  window.addEventListener('scroll', () => {
    header.classList.toggle('is-scrolled', window.scrollY > 12);
  }, { passive: true });
}

if (menuButton && mobileNav) {
  menuButton.addEventListener('click', () => {
    const open = mobileNav.classList.toggle('is-open');
    menuButton.setAttribute('aria-expanded', String(open));
    document.body.classList.toggle('menu-open', open);
  });
  mobileNav.querySelectorAll('a').forEach(link => link.addEventListener('click', () => {
    mobileNav.classList.remove('is-open');
    menuButton.setAttribute('aria-expanded', 'false');
    document.body.classList.remove('menu-open');
  }));
}

const revealObserver = 'IntersectionObserver' in window
  ? new IntersectionObserver(entries => entries.forEach(entry => {
      if (entry.isIntersecting) {
        entry.target.classList.add('is-visible');
        revealObserver.unobserve(entry.target);
      }
    }), { threshold: 0.08 })
  : null;

document.querySelectorAll('.reveal').forEach(el => {
  if (revealObserver) revealObserver.observe(el);
  else el.classList.add('is-visible');
});

document.querySelectorAll('[data-faq-button]').forEach(button => {
  button.addEventListener('click', () => {
    const item = button.closest('[data-faq-item]');
    const open = item.classList.toggle('is-open');
    button.setAttribute('aria-expanded', String(open));
  });
});

const search = document.querySelector('[data-doctor-search]');
const filters = [...document.querySelectorAll('[data-specialty-filter]')];
const doctors = [...document.querySelectorAll('[data-doctor-card]')];
let activeSpecialty = 'all';

function filterDoctors() {
  const query = (search?.value || '').trim().toLowerCase();
  doctors.forEach(card => {
    const name = card.dataset.name.toLowerCase();
    const specialty = card.dataset.specialty.toLowerCase();
    const matchesText = !query || name.includes(query) || specialty.includes(query);
    const matchesSpecialty = activeSpecialty === 'all' || specialty.includes(activeSpecialty);
    card.hidden = !(matchesText && matchesSpecialty);
  });
}

if (search) search.addEventListener('input', filterDoctors);
filters.forEach(button => button.addEventListener('click', () => {
  activeSpecialty = button.dataset.specialtyFilter;
  filters.forEach(item => item.setAttribute('aria-pressed', String(item === button)));
  filterDoctors();
}));
```

```python
def test_every_page_has_unique_metadata_and_one_h1(self):
    titles = []
    descriptions = []
    for rel in PHASE_ONE:
        html = read(rel)
        title = re.search(r"<title>(.*?)</title>", html, re.I | re.S)
        desc = re.search(r'<meta\s+name="description"\s+content="([^"]+)"', html, re.I)
        self.assertIsNotNone(title, rel)
        self.assertIsNotNone(desc, rel)
        self.assertEqual(len(re.findall(r"<h1\b", html, re.I)), 1, rel)
        self.assertIn('name="viewport"', html)
        titles.append(title.group(1).strip())
        descriptions.append(desc.group(1).strip())
    self.assertEqual(len(titles), len(set(titles)))
    self.assertEqual(len(descriptions), len(set(descriptions)))


def test_internal_html_links_resolve(self):
    for rel in PHASE_ONE:
        html = read(rel)
        base = (ROOT / rel).parent
        for href in re.findall(r'href="([^"]+\.html(?:#[^"]*)?)"', html):
            path = href.split('#', 1)[0]
            self.assertTrue((base / path).resolve().is_file(), f"{rel} -> {href}")


def test_images_have_alt_text(self):
    for rel in PHASE_ONE:
        html = read(rel)
        for tag in re.findall(r"<img\b[^>]*>", html, re.I):
            self.assertRegex(tag, r'\balt="[^"]+"', rel)
```
