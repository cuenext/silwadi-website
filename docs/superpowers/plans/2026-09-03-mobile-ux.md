# Patch 1: Mobile navigation and visual stability Implementation Plan

> **For agentic workers:** Use inline execution with review checkpoints. Steps use checkbox syntax.

**Goal:** Make the existing Silwadi static site reliable and polished at mobile and desktop widths without changing service information, Arabic content, or the original photo assets.

**Architecture:** Keep the existing static HTML/CSS/vanilla-JS architecture. Add an independently scrollable mobile navigation surface, replace shortcut separators with soft card styling, and add a small shared icon treatment to contact links. Preserve the existing menu state contract (`open`, `body.menu-open`, `aria-expanded`) while making it safe for touch and keyboard users.

**Tech Stack:** HTML, CSS, vanilla JavaScript, Python unittest contract tests, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-09-03-mobile-ux-design.md`

## Global Constraints

- Work only on `patch-1-mobile-ux`, based on `a73c895d00a96ee0ff7a4e25f737ac99c424721b`.
- Do not alter service taxonomy, Arabic URL structure, treatment content or image pixels in this patch.
- Use no new dependencies.
- Keep phone links `tel:`, email links `mailto:`, and visible text labels.
- Maintain `prefers-reduced-motion: reduce` behavior.
- Every implementation task ends with a test run and a commit.

### Task 2: Implement the mobile navigation and shortcut-card CSS

**Files:**
- Modify: `styles.css`

**Interfaces:**
- Consumes: existing `.mobile-nav`, `.mobile-nav__panel`, `.mobile-services__links` and `.care-shortcuts` selectors.
- Produces: scrollable mobile menu and borderless shortcut cards.

- [ ] **Step 1: Add minimal navigation behavior**

At the mobile breakpoints:
- Set `.mobile-nav` to `max-height:calc(100dvh - 103px)` (with a `100vh` fallback) and `overflow-y:auto`.
- Keep `body.menu-open{overflow:hidden}`.
- Set `.mobile-nav__panel` to `min-height:100%`, `overscroll-behavior:contain`, and `-webkit-overflow-scrolling:touch`.
- Preserve the existing fixed top offsets and z-index.

- [ ] **Step 2: Replace shortcut separators**

Change the shortcut grid to use a consistent `gap`, a quiet background and individual cards:
- Remove selector-level `border-left` and `border-right` rules.
- Add `border:1px solid var(--line)`, `border-radius:14px`, `background:var(--quiet)`, and a modest shadow to each card.
- Add `:hover` and `:focus-visible` states without layout shifts.
- Keep the fifth shortcut full width on small screens, but remove grid-rule borders.

- [ ] **Step 3: Verify the CSS contracts**

Run:
```bash
python -m unittest tests.test_patch23_mobile_ux -v
```
Expected: navigation/card tests still fail only for contact icon markup and app behavior.

- [ ] **Step 4: Commit the CSS change**

```bash
git add styles.css
git commit -m "fix: make mobile menu scrollable and shortcuts card-based"
```

### Task 3: Add consistent contact icons and menu focus behavior

**Files:**
- Modify: `index.html`, `contact.html`, `locations.html`, `app.js`, `styles.css`

**Interfaces:**
- Consumes: existing footer `.footer-address` text links and menu state functions.
- Produces: accessible phone/email icon rows and robust menu close behavior.

- [ ] **Step 1: Add inline SVG icon markup**

In each root-page footer contact block, wrap the existing telephone and email links as:
```html
<a class="footer-contact-link" href="tel:+97126262042">
  <svg class="contact-icon" viewBox="0 0 24 24" aria-hidden="true" focusable="false">…</svg>
  <span>+971 2 626 2042</span>
</a>
<a class="footer-contact-link" href="mailto:info@silwadidentalcentres.ae">
  <svg class="contact-icon" viewBox="0 0 24 24" aria-hidden="true" focusable="false">…</svg>
  <span>info@silwadidentalcentres.ae</span>
</a>
```
Use simple line icons (phone handset and envelope) with no external asset or icon font.

- [ ] **Step 2: Style the icon rows**

Add `.footer-contact-link` as an inline-flex row with a fixed 18px icon box, a small gap, and a clear hover/focus color. Keep text selectable and maintain the existing footer typography.

- [ ] **Step 3: Harden menu close behavior**

Keep the current `closeMenu` contract and:
- close on every mobile navigation link activation;
- close on Escape;
- reset `aria-expanded` to `false`;
- clear `body.menu-open`;
- avoid changing the `details` open state while the panel is scrolling.

- [ ] **Step 4: Run the full static test suite**

Run:
```bash
python -m unittest discover -s tests -p 'test*.py' -v
```
Expected: all existing tests plus `test_patch23_mobile_ux` pass.

- [ ] **Step 5: Commit the markup/JS change**

```bash
git add index.html contact.html locations.html app.js styles.css
git commit -m "fix: add contact icons and reliable mobile menu closing"
```
